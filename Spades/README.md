# Spades Simulator: Heurisics vs. Minimax

This project implements a Spades game simulator to compare two AI strategies:

- Heuristic based decision making
- Minimax search

The simulator runs a simulation of 1000 games and records the data to analyze


### Approaches

- Heuristic Agent: uses a given set of rules based on Spades strategy
- Minimax Agent: Uses depth-limited minimax with a state evaluation function to analyze future plays

### Running

run either simulator to generate data, then compare results:
- python spades_heuristic_simulator.py
- python spades_minimax_simulator.py
- python spades_compare_data.py
